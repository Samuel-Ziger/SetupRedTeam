# 🔒 Política de Segurança

## 📧 Reportando Vulnerabilidades

Se você descobrir uma vulnerabilidade de segurança neste repositório, por favor:

1. **❌ NÃO abra uma issue pública** no GitHub
2. **📧 Envie um email** para o mantenedor do projeto
3. **📝 Inclua detalhes** sobre a vulnerabilidade encontrada
4. **⏳ Aguarde resposta** antes de divulgar publicamente

## 🎯 O que Reportar

Reporte qualquer problema de segurança relacionado a:

- Exposição de credenciais ou informações sensíveis
- Vulnerabilidades em scripts que possam ser exploradas
- Problemas de configuração que comprometam segurança
- Qualquer outro problema relacionado à segurança

## 🛡️ Obrigado

Agradecemos por ajudar a manter este repositório seguro para todos!
