# 🗺️ Roadmap do Projeto

Este documento descreve as direções futuras e melhorias planejadas para o repositório.

---

## 🎯 Visão Geral

O objetivo é manter um repositório profissional, escalável e seguro para operações de Red Team e Pentest.

---

## ✅ Concluído

- [x] Estrutura básica do repositório
- [x] Scripts de setup para Windows e Kali Linux
- [x] Scripts de pentest automatizado
- [x] Scripts de reteste
- [x] Bibliotecas reutilizáveis (OPSEC, backup, relatórios)
- [x] Documentação inicial

---
